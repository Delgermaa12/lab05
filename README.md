## Давхар алдааны дараалал

Оюутан болон хичээл хоёулаа байхгүй үед сервер `ERROR_NO_STUDENT` буцаасан. Харин оюутан бүртгэлтэй боловч хичээл байхгүй үед `ERROR_NO_COURSE` буцаасан. Энэ нь сервер эхлээд оюутны бүртгэлийг шалгаж, дараа нь хичээлийн бүртгэлийг шалгаж байгааг харуулж байна.

## Боломжгүй хослол

Системд бүртгэлгүй оюутныг идэвхгүй төлөвтэй гэж үзэх нь логикийн хувьд зөрчилтэй. Учир нь оюутны бүртгэл байхгүй үед түүний төлөвийг тодорхойлох боломжгүй. Энэ нь тестийн нөхцөл боловсруулах үеийн логик ажиглалт болно.
